# Security Policy

## Supported Versions

Security updates are provided for the latest version on the `main` branch.

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly:

- Email: aditya463615@gmail.com

Please include:

- A description of the issue
- Steps to reproduce
- Impact assessment (what could an attacker do?)
- Any suggested fix (if you have one)

## Disclosure Process

- We will acknowledge receipt as soon as possible.
- We will investigate and work on a fix.
- We may request additional information.
- Please do not publicly disclose the issue until a fix is released.
